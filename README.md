# flight_path

Flight Path Tracker is a Flutter web-based project that allows users to visualize flight routes interactively — similar to Google Maps flight paths.
Built using Flutter, Google Maps API, and animated UI, it offers a smooth and modern web experience.

🧠 Features

✅ Interactive Google Map with flight path visualization
✅ Clean animated welcome screen
✅ Real-time flight path display using polylines
✅ Beautiful UI with Flutter animations
✅ Fully responsive web design
✅ Deployed on Vercel via GitHub
